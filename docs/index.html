See the flow behind every function.

Call Charts is a VS Code extension that draws a live call chart for the function under your cursor — hover for the picture, expand to trace execution from route to database. Powered by the TypeScript language server. No AI, no network, nothing leaves your machine.

  • →in — the exact line that invokes this function, from the caller on the hovered edge.
  • ↩out — its return expressions, straight from the body.
  • ▲guards — early exits: the if (…) return / throw lines that stop execution.
  • Δmutates — state writes (this.x =), so you know what a call touches.
  • ←called by — every caller by name: the blast radius before you edit.
  • ◷git — the last commit that touched these lines, via git log -L.

How it works.

The editor already knows the graph.

Call Charts asks the TypeScript language server the same questions that power “Go to Definition” — what does this call, who calls this — three levels deep each way.

The chart is drawn, not screenshotted.

A tidy-tree layout positions callers left and callees right of your function, colored by layer from the filename. Hover charts render into the tooltip; the expand view is a live page with tracing and zoom.

The card is extraction, not generation.

Signatures, guards, returns and mutations come from reading the source with strict rules; ownership comes from your local git. Deterministic — same code in, same card out.

Local, small, MIT.

Zero network calls, zero telemetry, zero runtime dependencies — a 70 KB install that talks only to your editor and your git.

Install.

ext install waleed.call-charts

Paste into VS Code's Quick Open (⌘P / Ctrl+P) — or search “Call Charts” in the Extensions panel, or grab it from the marketplace. Works in VS Code and Cursor, on TypeScript and JavaScript.
