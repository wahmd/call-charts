  • →in — the exact line that invokes this function, from the caller on the hovered edge.
  • ↩out — its return expressions, straight from the body.
  • ▲guards — early exits: the if (…) return / throw lines that stop execution.
  • Δmutates — state writes (this.x =), so you know what a call touches.
  • ←called by — every caller by name: the blast radius before you edit.
  • ◷git — the last commit that touched these lines, via git log -L.
